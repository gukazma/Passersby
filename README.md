# 我亦是行人 · Passing Through

> 人生如逆旅，我亦是行人。——苏轼《临江仙·送钱穆父》

一款横版像素风的人生模拟游戏。画面视角是正面看临街的楼，从略高处俯视人行道和马路。你是城市「澜港」里一个普通的行人：在街上走、进店、和街坊聊天，每个人都有自己的日子要过。

## 运行

安装 Godot 4.6，双击 `运行.cmd`（Godot 默认路径为 `D:\tools\godot\4.6.3`）。也可以在 Godot 里打开 `game/project.godot`。

| 按键 | 作用 |
|---|---|
| A / D（← →） | 沿街左右走 |
| W / S（↑ ↓） | 在人行道上往里或往外走（背面 / 正面行走） |
| W/S + A/D | 斜着走 |
| 按住 Shift | 跑 |
| 空格 / E | 说话、摸狗、坐下或起身、进门；在门前按 W 进门，在斑马线上按 S 过马路 |
| P | 主角举起手机拍照（截图存到仓库根目录的 `截图/`） |
| H | 隐藏操作说明 |
| Esc | 退出 |

## 目录

| 目录 | 内容 |
|---|---|
| `game/side/` | 横版玩法代码：`actor.gd`（角色动画与根运动）、`npc.gd`（居民日程与动作）、`scene.gd`（街段/室内）、`side_main.gd`（主控） |
| `game/side_data/` | `world.json`（街段连接、居民、座位、BGM）、`scenes/`（街道和室内美术）、`chars/`（角色动画）、`bgm/` |
| `art/a13_style/` | 定稿画风样张与主角设定稿 |
| `docs/` | 开发计划 `PLAN.md`，版本说明 `versions/` |
| `tools/` | 通用像素化脚本、场景像素化 `scene/pxscene.py` |
| `.claude/skills/passersby-dev/` | 本项目的开发规范与美术/动画流水线（边做边更新），用户反馈记录在 `references/feedback_log.md` |

旧的俯视角版本（A1–A1.2）已经清理出仓库，需要时查看标签 `A1.2`。
