# 我亦是行人 · Passing Through

> 人生如逆旅，我亦是行人。——苏轼《临江仙·送钱穆父》

一款像素风、俯视角（3/4 视角）的开放世界人生模拟游戏。

你是这个世界里一个普通的行人：
- 自由选择职业，投简历、面试、上班、赚钱、升职、跳槽，也可以自己开店。
- 城里每个居民都有自己的日程、需求、记忆和故事。
- 所有房子都能进去，每个人都能聊天，支线从居民的人生里长出来。
- 街上随时会发生随机事件；你做过的事会被记住、被传开，并改变主线走向。
- 世界随版本持续扩张：从第一座城市「澜港」开始，一座一座城市点亮。

## 开发方式

按系统拆成一个个小版本，每版做完由制作人亲自试玩，再按反馈调整玩法和美术。计划见 [docs/PLAN.md](docs/PLAN.md)。

## 目录

| 目录 | 内容 |
|---|---|
| `game/` | Godot 4.6 工程：像素城市（AI 整块街区、行人、车流、红绿灯、遮挡、碰撞）；`assets/variants/` 是 A1 的 6 套城市（3 种风格 × 2 种比例） |
| `art/concept/` | 概念美术（AI 生成：主视觉、世界地图、室内、人物头像、事件、结局） |
| `docs/` | 开发计划 `PLAN.md`；每个版本的说明与测试清单在 `versions/`；`concept_v1/` 是早期概念讲解阶段的方案（仅供参考） |
| `tools/art/` | 像素美术流水线：AI 出图、真像素还原、锁头防闪脸、根运动测量、站立帧生成 |
| `tools/city/` | 城市街区出图提示词与拼城脚本 |
| `tools/concept_video/` | 概念讲解视频用的网页模拟（canvas 版城市模拟，仅供参考） |

## 运行

安装 Godot 4.6，然后双击 `运行.cmd`（默认路径 `D:\tools\godot\4.6.3`），或者在 Godot 里打开 `game/project.godot`。

当前版本：**A1.1 手感与穿帮修复**（说明与测试清单见 [docs/versions/A1.1.md](docs/versions/A1.1.md)；A1 见 [A1.md](docs/versions/A1.md)）。

| 按键 | 作用 |
|---|---|
| 方向键 | 走路 |
| 按住 Shift | 跑步 |
| 1 / 2 / 3 | 城市风格：现状·彩色小镇 / 岭南骑楼老街 / 港台现代街巷 |
| R | 人和楼的比例 100% / 85% |
| Z | 镜头远近 |
| T | 时间色调 |
| P | 拍照模式（方向键移镜头、Z 远近、回车保存截图到 `截图/`） |
| Tab | 自动巡游 |
| 空格 | 交互 |
| H | 隐藏说明 |
| Esc | 退出 |

## 美术约定

- 角色：每方向 8 帧行走（另有 8 帧跑步），按测量的根运动连续前进，脚步不打滑；每个方向都有专门的站立帧（`*_idle.png`），侧面站立是正侧面、双脚着地。
- 行道树：每条人行道一排、一棵一棵、等间距，树坑和树冠都不进车道。
- 城市：AI 以街区为单位整块绘制，楼挨楼、统一正交 3/4 视角；程序只做道路、碰撞、遮挡、车流和行人。
- 界面：暖色浅色系，不用蓝紫色调。
