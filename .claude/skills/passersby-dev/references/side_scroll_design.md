# 横版街道玩法设计（A1.3 起）

11-27 用户定：画面采用样张 A 的视角（正面看楼，人行道和马路从上方略俯视），操作改成「蜡笔小新那种横版移动」，不再是俯视自由走。

## 1. 尺寸与比例（一切以主角身高为尺）

- 原生分辨率 960×540，游戏里 ×2 显示。主角身高 H ≈ 110 px，对应 1.7 m，所以 **1 m ≈ 65 px**。
- 走路速度 1.3 m/s ≈ 85 px/s；跑步约 2 倍。具体速度由 F 根运动决定：每帧前进距离 × 帧率。
- 室外和室内用同一把尺：

| 物件 | 真实尺寸 | 像素 |
|---|---|---|
| 门 | 2.1 m | 约 136 px |
| 一层楼高 | 3.2 m | 约 210 px |
| 桌面 | 0.75 m | 约 49 px |
| 凳面 | 0.45 m | 约 29 px |
| 柜台 | 1.0 m | 约 65 px |
| 室内吊顶 | 2.8 m | 约 180 px |

- 室内图出完后，量门高和桌高，用 `pxscene.py --pixel` 把比例缩到上表，误差 ≤ 5%。演示视频里要放标尺图证明比例对。

## 2. 一条街的分层（从后往前）

| 层 | 内容 | 视差 |
|---|---|---|
| 远景 | 天空、远处楼群或海港 | 0.3 |
| 楼排 | AI 整排画的临街楼（洋红底抠图），门、招牌、窗 | 1.0 |
| 人行道 | 可走的纵深带，在楼脚和路缘之间，深约 70 px | 1.0 |
| 马路 | 车辆双向行驶，人不能随便走上去 | 1.0 |
| 前景 | 偶尔有近处的树冠、栏杆、路牌 | 1.15 |

- 行道树、路灯、自行车、摊位都是独立物件，按脚底 y 排序，人可以从前面或后面经过。

## 3. 主角移动

- **A / D（← →）**：沿街左右走，人物只有朝左、朝右两个朝向。朝左用镜像帧。
- **W / S（↑ ↓）**：在纵深带里前后走。单按 W 或 S 时，人物转成背面（走离镜头）或正面（走向镜头），播放对应的 8 帧行走。速度由投影后的根运动决定，约为横向的 0.37 倍，近大远小的透视感就靠它。斜着走（W/S 加 A/D）用侧面行走帧，横纵速度合成。用途：
  - 绕开行人和物件；
  - 走到门前；
  - 走到路缘。
- **Shift**：跑。松开方向键停下，进入站立呼吸动画。
- **空格 / E**：交互，包括说话、进门、看橱窗、坐下。
- 参考：《蜡笔小新 我与博士的暑假》每个区域用固定镜头，背景是手绘 2D 图，小新是 3D 模型，能在画面里自由往纵深走，走到画面边缘切换区域。我们是像素版的同类做法：纵深带在街上较浅（约 76 px），在庙前地、渡口、室内较深。
- 镜头只跟随横向移动：往行走方向多看出 80 px，平滑跟随，到街道两端停住。纵向固定，不晃。
- 碰撞只在纵深带内生效：
  - 物件在脚底占一个小矩形；
  - 人和人之间是软推开，不会卡死。

## 4. 街道怎么衔接（城市是一张「街段图」）

- 城市拆成**街段**：一条街在两个路口之间、面朝一侧楼的一个横条，长 2–4 屏。
- 三种衔接：
  1. **路口转弯**：走到街段一端的街角，出现「↑ 滨江路」的提示，按 W 拐进横街。转场 0.4 s 横向推镜，屏幕上出现街名卡。拐进去后，主角从新街段的对应端走出来。
  2. **直行过路口**：在街角继续按 D，走过横街的斑马线，到同一条街的下一段。
  3. **过马路**：只能在斑马线或红绿灯处。在斑马线上按 S，主角走下路缘、穿过马路，切换到对面一侧楼的街段。这时镜头掉头，左右方向互换。小地图上会标出主角在哪一侧。
- 车不会撞人：车在斑马线前等人。乱穿马路以后可以做罚款。
- 每个街段的数据：
  - 两端各连到哪里；
  - 斑马线位置和对面街段；
  - 门的列表：门编号来自设定集 bible.json，记录 x 范围和进到哪个室内。

## 5. 进门与室内

- 走到门前（纵深带靠楼的一侧，x 在门的范围内）会出现提示，按 W 或空格进门：
  - 播放背面行走 3–4 帧，人走进门洞，在门里变暗；
  - 画面淡出淡入，进入室内。
- **室内**是剖面视角，镜头朝里看，和街上的方向一致：
  - 后墙、地板纵深带、家具，大多一屏宽，大店可以 1.5 屏；
  - 主角从画面**下沿**走进来，表示从镜头这一侧的街门进屋；
  - 往下走出下沿就是出门，回到街上那扇门前，面朝街。
- 家具：
  - 柜台、桌凳、货架在纵深带里占脚底矩形，人可以绕过去；
  - 能交互的家具有提示。比如坐下：人走到凳子旁按空格，切换成坐姿帧，坐上去。
- 室内 NPC：
  - 店主在柜台后面待机（站姿或干活动作），按空格对话；
  - 食客坐着吃面，两帧循环。

## 6. NPC 移动与交互

- 街上 NPC 跟玩家用同一套横版移动（左右走、纵深挪），自己有一张小日程：

| 行为 | 说明 |
|---|---|
| 散步 | 在几个点之间来回走 |
| 购物 | 走到某家门前 → 背面进门（消失）→ 过一会儿出来 |
| 停留 | 看橱窗用背面帧，在摊位前站一会儿 |
| 打招呼 | 玩家靠近时转头冒气泡：「早晨！」 |

- 避让：
  - 同一深度迎面走来时，一方挪到另一条深度错开，不穿模；
  - 玩家挡路时，NPC 停下等，或者绕开。
- 对话：
  - 走到 NPC 身边按空格，双方转身面对面；
  - 底部出对话框：像素字体、人物名、2–3 句，有选项时上下选。
  - 对话内容来自设定集里的居民档案。

1. 永安街北侧：一条约 3 屏长的完整街段，有十来栋楼、两处斑马线、行道树、路灯和摊位。
2. 街角拐进滨江路：约 2 屏，沿河、有栏杆和渡口。
3. 斑马线过到永安街南侧：短街段，用来演示镜头掉头。
4. 陈记云吞面室内：店主陈伯、食客、桌凳、柜台和汤锅，比例按 §1。
5. 主角：走、跑、站立、背面进门、正面对话。NPC：3–4 个路人加 2 个室内人物。
