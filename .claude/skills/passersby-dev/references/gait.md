# 步态参考（姿势模特的数据来源）

正常步行的矢状面关节角，取自 Perry / Winter 常模，各家数值差 ±5° 以内。周期以 0% = 本侧脚跟着地计。

| 关节 | 关键点 |
|---|---|
| 髋（+屈） | 着地 30°，10% 28°，30% 8°，50% 最大伸展 −10°，62% 离地约 0°，87% 最大屈 32° |
| 膝（+屈） | 着地 5°，15% 承重屈 18°，40% 接近伸直 4°，62% 离地 38°，72% 摆动最大屈 60°，97% 伸直 5° |
| 踝（+背屈） | 着地 0°，7% 跖屈 −6°，45% 背屈 10°，62% 蹬地跖屈 −16°，80% 回到 0° |

- 足趾离地约在 62%，所以支撑相约占 62%、摆动相约占 38%。另一侧腿相位差 50%。
- 手臂和同侧腿方向相反：肩角约为 −0.6 ×（髋角 − 10°），肘总是微屈，向前摆时屈得更多。
- 动画四个关键姿势：
  - contact：双脚着地，前脚跟落地，后脚尖准备离地；
  - down：身体最低，承重腿膝弯；
  - passing：摆动腿从支撑腿旁经过，膝屈最大，脚尖朝下；
  - up：身体最高，后脚蹬地。
- 摆动脚不能保持水平，要跟着小腿转，这是 11-27 用户指出的「脚折叠」问题。
