# 《我亦是行人》Passing Through 分版本开发计划（边做边调）

> 11-26 调整：不用「万事屋」。主角是一个普通市民，像《模拟人生》一样自由选择职业：投简历应聘、面试、上班完成工作任务、赚钱、升职、跳槽、兼职，也可以自己开店。

> 名字（11-26 定）：《我亦是行人》，出自苏轼《临江仙·送钱穆父》「人生如逆旅，我亦是行人」。英文名 Passing Through（推荐，待确认）。

每一版只做一个系统，做完交给你亲自玩。你提的意见我改成 .1、.2 小版本。你说「这版可以了」，我再开始下一版。

## 每一版交付什么

- 一个文件夹，双击 `运行.cmd` 就能玩（Godot 4，Windows 桌面版）。
- 更新说明：这版做了什么。
- 测试清单：5–10 条，告诉你重点看哪里。
- 调参面板（F1）：速度、比例、镜头距离、颜色等可以边玩边拖动；你觉得合适的数值告诉我，我写死进去。
- 灵感建议：3–5 条，可选，你挑感兴趣的。

## 阶段 A · 打地基（先定手感和美术，后面全部依赖它）

| 版本 | 内容 | 你重点测什么 |
|---|---|---|
| A1 美术风格与人物比例（11-26 交付测试） | 同一条街做 2–3 种风格和比例方案（角色高度、一层楼高、镜头远近），按键切换对比 | 哪种好看、人和楼比例是否舒服、街道密度 |
| A1.1 手感与穿帮修复（11-27 交付测试） | 连续平滑行走、跑步（Shift）、正侧面站立帧、自由过马路、行道树一排一棵、楼顶凸起遮挡、拍照模式（P） | 卡不卡、跑步手感、过马路、遮挡 |
| A1.2 楼顶遮挡、跑步不滑、WASD、新画法试验街（11-27 交付测试） | 楼顶凸起只遮挡不碰撞；跑步按步幅重做；WASD；永安街试验街：整排楼抠底、两端完整、高低错落、程序叠加中文招牌 | 跑步脚滑不滑、新画法好不好看 |
| 设定集与主角设计（11-27 交付审阅） | 《第一张地图设定集》：分区（老城区骑楼 / 新区港台街巷 / 商务区玻璃楼）、每栋楼每扇门住谁做什么、招牌名、居民故事；主角 3 套方案 | 世界观、人物、楼和门的安排；先定稿再建城 |
| A1.3 新城市重建 | 按设定集重画城市：风格随街区变化、真实中文像素招牌、街区两端不再有被裁切的树和楼；换上新主角（走、跑、站立） | 城市是否有故事感、招牌、风格过渡 |
| A2 主角操控手感 | 走、跑、停（站立帧）、8 向或 4 向、碰撞贴墙滑、镜头跟随、楼挡人时淡出 | 跟手不跟手、步频和速度是否打滑、镜头晕不晕 |
| A3 进门与室内 | 走到门口转场进屋，室内行走、出门，先做 2 间房 | 转场节奏、室内比例、家具碰撞 |

## 阶段 B · 让城市活起来

| 版本 | 内容 | 你重点测什么 |
|---|---|---|
| B1 时间与昼夜 | 游戏时钟、昼夜光照、路灯，时间流速可调 | 一天多长合适、夜景氛围 |
| B1.5 天气与季节 | 晴、炎热、刮风、下雨（地面反光、行人到骑楼下躲雨）、雷电、下雪；季节与节日换装（春节挂灯笼） | 天气氛围、多久变一次天、行人反应 |
| B2 居民日程 | 10 个居民按日程上班、开店、吃饭、回家 | 街上像不像活的、人多还是人少 |
| B3 对话与人物档案 | 对话框、头像、分支选项、好感度、人物档案页 | 对话节奏、字体、档案信息量 |
| B4 需求、记忆与传闻 | 饿了去吃饭、累了收摊；记住你做过的事；传闻扩散（带调试视图，能看到每个人在想什么） | 居民的反应合不合理、传闻传得快不快 |

## 阶段 C · 核心玩法

| 版本 | 内容 | 你重点测什么 |
|---|---|---|
| C1 背包与金钱 | 拾取、使用、商店买卖、背包界面 | 背包操作是否顺手、物品图标 |
| C2 求职系统 | 招聘 App / 人才市场、岗位要求（技能、驾照、证书）、投简历、面试（对话选择 + 属性判定）、录用、排班 | 应聘流程是否有趣、门槛是否合理 |
| C2.x 职业（每个职业一版） | 先做 1 个（如外卖骑手或便利店店员）：上班打卡、工作玩法、绩效、工资、升职；之后逐个加：面馆帮工、出租车司机、摄影记者、修理工、夜市摊主、快递员、咖啡师… | 工作玩法好不好玩、收入节奏、会不会重复无聊 |
| C2.y 技能与成长 | 驾驶、厨艺、沟通、修理、摄影等技能，随工作和练习成长，解锁更好的工作 | 成长曲线 |
| C3 骑自行车 | 上下车、加速、转弯、停放、撞人撞车的反应 | 速度感、操控、上下车是否顺 |
| C4 开车 | 车辆操控、红绿灯、交通规则（罚款、驾照，不做犯罪）、停车 | 驾驶手感、交通是否真实 |

## 阶段 D · 事件与剧情（每个都单独一版）

| 版本 | 内容 | 你重点测什么 |
|---|---|---|
| D1 随机事件框架 + 事件「周伯摔倒」 | 事件触发条件、围观、选择、后果和传闻 | 触发频率、是否自然、后果是否看得见 |
| D2… 更多随机事件 | 每版 1–2 个：台风停电、夜市失火、孩子走丢、街头求婚… | 同上 |
| D3 支线「老钟表铺的约定」 | 完整一条支线 | 剧情节奏、线索是否好找 |
| D4 主线第一章 + 世界变量 | 街坊信任、名声、证据，影响后续章节 | 你的行为有没有被体现出来 |
| D5 恋爱系统原型 | 先做 1 个可攻略角色：好感、约会、专属事件 | 心动感、节奏、会不会太功利 |

## 开始前需要你定的（不影响 A1）

- 平台：先做 Windows 桌面版（Godot），以后可以导出手机或网页版。
- 主角身份与故事基调、城市风味、要不要恋爱：放到对应阶段再定（A1 会让你先挑城市风格）。
