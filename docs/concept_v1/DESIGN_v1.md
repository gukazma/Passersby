# 《烟火之城》玩法方案 v1（暂定名）

像素风、第三人称俯视角（3/4 视角）的开放世界城市生活模拟游戏。像 GTA 一样自由，但主角是一个普通人，玩法不是犯罪。

## 一、一句话理解

在一座虚构的亚洲海港城市「澜港」里，几千个居民各自过着自己的日子：上班、开店、吵架、恋爱、生病、搬家。你可以自由探索整座城市，所有房子都能进，每个人都能聊天。你做过的事会被记住、被传开，并且一点点改变主线的走向。城市跟着版本持续扩张。

## 二、城市设定：澜港

- 一座虚构的亚洲海港城市，融合香港、台湾、广州、上海老城的气质。
- 区域：骑楼老城区、渔港码头、霓虹夜市、玻璃幕墙商务区、半山旧住宅、离岛。
- v1.0 只开放老城区和码头，其余区域被雾挡住，随版本解锁。

## 三、主角与核心玩法

- 主角林屿，26 岁，回到澜港，接手舅舅留下的「万事屋」（暂定，身份和基调待定）。
- 万事屋什么活都接：送货跑腿、开出租、修家电、找猫、调解纠纷、给报社拍照。
- 不犯罪版本的 GTA 式任务：

| GTA 式玩法 | 万事屋版本 |
|---|---|
| 飙车 | 限时送货、送病人去医院 |
| 追逐 | 追偷包贼、追跑掉的猫 |
| 潜入 | 帮报社暗访黑心工厂 |
| 调查 | 寻人、寻物、查真相 |

- 成长：赚钱 → 升级店面、租更好的房子、换交通工具（旧自行车 → 电驴 → 二手车 → 小船去离岛）。

## 四、活着的居民（核心系统）

每个居民都有：

- **档案**：名字、年龄、职业、住址、家人、性格、秘密。
- **日程**：一天的作息（例如早餐摊主 05:30 备料、06:00 出摊、10:30 收摊、14:00 打麻将……）。
- **需求**：饥饿、疲劳、心情、钱包。需求超过阈值会临时改变计划（累了提前收摊、饿了去面馆排队）。
- **记忆**：记住你对他做过的事，影响好感和以后的反应。
- **关系网**：家人、朋友、对头；关系会随事件变化。
- **传闻**：听到的事会传给熟人，在街区里扩散（你的名声就是这样形成的）。

目标效果：像 GTA6 预告里展示的那样，每个路人都在过自己的生活，对你、对彼此都有反应，而且会记住。

### 分层模拟（几千人同时运转）

| 层级 | 范围 | 做法 |
|---|---|---|
| 完整模拟 | 玩家身边 | 逐帧移动、动画、交互、气泡 |
| 简化模拟 | 同一街区 | 低频更新位置和状态 |
| 统计结算 | 全城 | 每个游戏小时结算一次：收入、关系、事件 |

离开一个街区，那里的生活不会暂停：过几天回来，可能新开了店、有人搬走、物价变了。

## 五、随机事件

- 事件从模拟中自然产生：例如周伯腿脚不好、雨天路滑、赶时间 → 在路口摔倒；周围居民会围观、打电话、拍视频。
- 玩家可以帮忙或走开；结果写进记忆和传闻：「万事屋的小林人不错」→ 委托变多、相关人物好感上升、在后面的剧情里回报你。
- 导演系统按时间、天气、进度补充投放：台风停电、夜市失火、孩子走丢、街头求婚等。
- 同一件事，玩家在场和不在场，结果不同。

## 六、所有房子都能进

- 进门方式像《宝可梦》：走到门口 → 画面转场 → 室内（俯视房间，后墙可见）。
- 面馆、钟表铺、学校、医院、居民家……每个房间都有人，每个人都能聊天。
- 支线从居民的人生里长出来：例如钟表铺钟伯的怀表停在三点十七分，引出支线「老钟表铺的约定」，故事一直延续到离岛开放的版本。
- 每个居民都有一条「人生线」，随版本继续往下写。

## 七、主线：行为决定走向

- 主题：这座城市会变成什么样。开发商海晟集团推进「新港计划」，老城区一半要拆。
- 各方：街坊会、老商户、记者小满、海晟集团陈总。
- 结局由平时的行为累积决定，而不是最后的几个选项：

| 世界变量 | 来源 |
|---|---|
| 街坊信任 | 帮过谁、得罪过谁 |
| 城市名声 | 传闻扩散 |
| 海晟关系 | 是否接他们的委托 |
| 证据 | 调查、暗访、拍照 |

- 示例：扶过周伯 → 听证会上周伯的儿子出面作证；没管夜市失火 → 第四章夜市被整顿关停。
- 结局：老街完整保留 / 改成网红商业街 / 拆一半留一半。地图会跟着结局改变。

## 八、长期更新与地图扩张

| 版本 | 新区域 | 内容 |
|---|---|---|
| v1.0 | 老城区 + 码头 | 40 栋可进入建筑，120 位有完整故事的居民，主线第一章，10+ 种工作 |

- 节日与季节活动：春节、中秋、台风季、夜市节。

## 九、技术方案

- 引擎：Godot 4。
- 城市美术：AI 整块画街区（楼挨楼、统一正交 3/4 视角），再还原成真像素；程序只做道路、碰撞、遮挡、车流和行人。
- 角色：8 帧四方向行走，按测量的根运动前进，脚步不打滑；每个方向有专门的站立帧。
- 居民数据驱动：一个居民 = 一张表格（档案、日程、需求、性格、秘密、支线）+ 一套通用行为规则，策划可以批量添加。
- 对话：核心剧情由人写；闲聊可以考虑用本地小模型生成（可选，需要控制一致性）。

## 十一、需要你确认的方向

1. 主角的身份与故事基调（万事屋青年？记者？外卖员？温情 / 悬疑 / 轻喜剧）
2. 城市更偏哪种味道：香港、台湾、上海还是东南亚
3. 要不要加入恋爱和养成（好感度、约会、成家、店铺经营）
