# A1.2 · 楼顶遮挡、跑步不滑、WASD、新画法试验街

A1.1 试玩反馈（11-27 第二轮）的修改。

## 怎么玩

双击 `运行.cmd`。**按 4 进「永安街试验街」**（新画法），按 1/2/3 回到 A1 的城市。

| 按键 | 作用 |
|---|---|
| WASD / 方向键 | 走路 |
| 按住 Shift | 跑步 |
| 1 / 2 / 3 / 4 | A1 城市三种风格 / 永安街试验街 |
| R | 人和楼的比例（试验街只有一种） |
| Z / T | 镜头远近 / 时间色调 |
| P | 拍照模式 |
| Tab / 空格 / H / Esc | 自动巡游 / 交互 / 隐藏说明 / 退出 |

## 改了什么

| 你的反馈 | 修改 |
|---|---|
| 屋顶凸起为什么做成碰撞，应该是遮挡 | 楼顶的楼梯间、水箱只遮挡、不碰撞：人可以走到它们"后面"，被它们挡住（挡住时楼会半透明，方便看到自己） |
| 跑步脚很滑 | 原因：AI 画的跑步步幅太小（脚每个循环只后移 14–23 像素，身体却走 48 像素）。重做跑步：上身沿用 AI 画的，腿按步幅表逐帧绘制，着地那只脚后移的距离和身体前进的距离逐帧相等（实测误差 0 像素）；16 帧、84 像素/秒（走路的 1.8 倍），每帧画面里脚的漂移只有 3 像素 |
| 要 WASD 控制方向 | WASD 和方向键都能走 |
| 房屋边缘还有剪裁 | 新画法（见试验街）：AI 一次画一整排楼，左右和上方都留空白背景，再自动抠掉背景，所以两端是完整的山墙，树、台阶、花盆都不会被切 |
| 房子都一样高，不真实 | 试验街的楼高低错落：2 层的凉茶铺、7 层的何家唐楼、单层的天后古庙、带钟楼的永安小学…… |

## 永安街试验街（按 4）

- 内容来自《第一张地图设定集》：北排 L01 陈记云吞面、L02 福安堂凉茶、L03 钟记钟表行、L04 永和五金、L05 何家唐楼（楼下何记烧腊）、L06 永安茶楼；南排 L07 新华理发、L08 永安街坊会、L09 天后古庙、L10 永安街市、L11 拾光书店、L12 永安小学。
- 招牌是程序叠加的真实像素中文（AI 只画空白招牌板），以后居民开店，招牌就写他起的店名。
- 每栋楼单独遮挡、单独淡出；楼主体有碰撞，楼顶上伸出来的东西只遮挡。
- 行道树种在楼与楼交界处，不挡门和招牌。

## 测试清单

1. 跑步（Shift）：脚还滑不滑？速度合适吗？走↔跑切换顺不顺？
2. WASD 手感。
3. A1 城市里走到后巷，贴着楼梯间、水箱走：是不是被挡住、不会被卡住。
4. 试验街：楼的高低错落、两端是否完整、有没有哪里还像被切过。
5. 招牌字：大小、清晰度、颜色；5 个字的招牌会自动加宽，看看合不合适。
6. 这种画法（偏正立面、屋顶露得少）和 A1 那种（屋顶露得多）你更喜欢哪种？

## 已知问题

- 试验街南排楼朝南（3/4 视角只能看到朝南的门面），从永安街看到的是它们的屋顶；设定集里南排的门要改成朝南（或开侧门）。
- 骑楼底下的走廊暂时不能走进去（需要把柱子单独做一层），留到下雨躲雨那一版一起做。
- 何家唐楼画成了 7 层（设定集写的是 4 层加天台），以设定集为准还是保留 7 层，等你定。
- 主角还是原来的形象，新主角等设定集定稿后替换。
