# A1.5 · 修正 A1.4 试玩反馈：光影、鸟、猫狗步态、碰撞、干净的界面

## 怎么玩
双击 `运行.cmd`。界面上平时不再显示任何文字：走到人、门、长椅、狗旁边按空格就能交互（W 进门，S 过马路，P 拍照，T 时间快进）。

## 这版改了什么（对应 A1.4 反馈）
- **面馆蒸汽被原图的静态雾挡住**：抠掉立面图和陈记柜台道具上画死的蒸汽；粒子蒸汽改到锅口（之前位置也偏了），并参与前后遮挡，路过的人挡在蒸汽前面；蒸汽稍浓一点。
- **看不到影子随太阳变化**：新的太阳影子——人、猫狗、车、树、路灯、长椅、报亭、楼都按自己的剪影投影：早上斜向右、中午短、下午斜向左并拉长、日落前淡出。人走路时影子跟着动作变。所有影子画在一层，重叠处不叠黑。
- **经过猫狗时人卡住**：猫狗不再挡人（猫狗之间也不互挡）；迎面撞到人会自动往旁边让一步绕过去。
- **鸽子一直在天上飞、鸟没有遮挡**：按城市鸟的真实习性重做——车不惊鸟；人走近先走开；贴得很近、有人跑过来、狗冲过来才整群惊飞；鸽子绕一圈后落在路灯顶、路牌、栏杆、屋脊或远一点的地面，歇一会儿没人了再回来觅食；麻雀躲进树冠；海鸥在海面上空借风盘旋。鸟按所在位置参与前后遮挡（会被树、路灯、行人挡住）。
- **猫狗步态**：按真实四足动物步态重做——狗走路是「左后-左前-右后-右前」四拍，旺财快步是对角腿同步；三段式腿（肘向后、膝向前、跗关节向后），步幅约 1.8–2 倍肩高；猫身体放低、尾巴竖起、后脚踩前脚的脚印。速度：狗约 1 m/s，猫约 0.6 m/s。
- **撞到东西时转向和脚抽风**：动作按「实际怎么移动」选择（贴墙斜走 → 侧面走；横着被挡 → 正面/背面走；完全走不动 → 站住），不再在走和站之间每帧来回切；居民在障碍物角上也不会上下抖了。
- **跑步时影子悬空**：跑步帧里脚离地 10–19 px（叶俊走路也离地 10 px，黄丽、乐乐 2–3 px），已全部贴回地面；素材检查新增「悬空」规则。
- **界面去掉冗余**：去掉头顶按键提示、底部操作说明、左上地名、右上时钟、转场大字、随机冒出的情绪气泡、「已保存截图」气泡；只保留对话框（对话框里「空格 ▶」也换成一个小 ▼）。居民打招呼、门锁着时主角说的话保留。

## 测试清单（请重点看）
1. 影子：按 T 快进，看一天里影子方向和长短的变化是否自然；楼的阴影条是否合适。

5. 界面是否够干净（没有提示后，交互是否还好找）。
