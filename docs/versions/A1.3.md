# A1.3 · 横版玩法、新画风、居民动作与音乐

## 怎么玩

双击仓库根目录的 `运行.cmd`。

| 按键 | 作用 |
|---|---|
| A / D | 沿街左右走 |
| W / S | 在人行道上往里或往外走（背面 / 正面） |
| W/S + A/D | 斜着走 |
| 按住 Shift | 跑 |
| 空格 / E | 说话、摸狗、坐长椅（再按起身）、进门 |
| 门前按 W | 进门；室内往下走出画面就是出门 |
| 斑马线上按 S | 过马路，到对面那一侧 |
| P | 举起手机拍照（截图存到 `截图/`） |
| H | 隐藏说明 · Esc 退出 |

## 这版做了什么

- 画风：选定样张 A，像素再做细一倍。原生 960×540，放大 2 倍显示。招牌字由 AI 直接写在原图上。
- 横版移动：左右、前后（正面和背面行走）、两个斜向、跑步。全部用根运动，脚不打滑。
- 街道：
  - 永安街北侧（10 间铺面），约 3.8 屏；
  - 永安街南侧；
  - 滨江路；
  - 陈记云吞面的室内，比例按一米七的人等于 110 像素换算。
- 衔接：走到街角拐进滨江路，斑马线过马路到南侧，进门到室内。
- 居民：每个人的步态不同。罗伯会进出凉茶铺、坐凳喝茶；叶永和在店门口抽烟；黄丽聊到好笑处会和你一起笑；乐乐逗小狗旺财；叶俊看手机赶单；陈伯在柜台后打汤；食客坐着吃面。
- 主角可以坐长椅、摸狗、拍照，聊天时会跟着笑。
- 背景音乐：老街、滨江、面馆各一首，温馨风格的原创纯音乐。

## 测试清单

1. 左右走、前后走、斜走、跑：步子和移动速度对得上吗？哪个方向看着别扭？
2. 前后走的速度（约为横向的一半）和人行道的纵深，是否舒服？
3. 街道长度、楼的高低错落、招牌字，看着像不像一条真的老街？
4. 进门后的室内：人、桌子、凳子、柜台的比例对不对？
5. 居民的动作和步态：能不能一眼看出谁是老人、谁健身、谁胖？
6. 坐长椅、摸狗、拍照的手感；对话里一起笑的效果。
7. 过马路和拐弯的转场：方向感会不会乱？
8. BGM 的风格对不对？每个场景你喜欢哪一首（候选见视频「BGM候选试听」）？

## 已知问题

- 室内画面四周有深色剖面外框，房间只占约 768×432，地板也偏浅，只能放一排桌子。
- 正面和背面行走、斜走的根运动用的是模特的设计值，有轻微脚滑（3–5 像素）。
- 路名牌偏小。
- 主角设定稿里「走路」那一格是概念图；游戏里实际的动画是按姿势模特重新画的。

## 灵感（可选）

- 雨天：骑楼下躲雨、地面反光，行人撑伞走路（伞也用姿势模特画）。
- 居民之间互相聊天、递东西，不只和主角说话。
- 摸狗之后旺财会跟着你走一段。
- 拍的照片存进一本「街坊相册」，以后可以送给照片里的人。
