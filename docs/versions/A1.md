# A1 · 美术风格与人物比例

## 怎么玩

双击仓库根目录的 `运行.cmd`。

| 按键 | 作用 |
|---|---|
| 方向键 | 走路 |
| 1 / 2 / 3 | 切换城市风格：现状·彩色小镇 / 岭南骑楼老街 / 港台现代街巷（主角原地不动，方便对比同一位置） |
| R | 切换人和楼的比例：100%（门比人略高）/ 85%（楼更矮、城更紧凑；布局会变，回到起点） |
| Z | 镜头远近：近（×4）/ 中（×3）/ 远（×2） |
| T | 时间色调：白天 / 黄昏 / 夜晚（只是整体调色，路灯和窗光在 B1 做） |
| Tab | 自动巡游开关（不想走路时看整座城） |
| 空格 | 和身边的人说话、用售货机 |
| H | 隐藏/显示说明 |
| Esc | 退出 |

## 这版做了什么

- 同一座城（9 个街区）用 AI 按原布局重画了两种亚洲风格：**岭南骑楼老街**、**港台现代街巷**，和原来的**彩色小镇**一起，按 1/2/3 即时切换。
- 每种风格各做了两种比例（100% / 85%），一共 6 套城市。
- 镜头远近三档，时间色调三档。
- 所有人物停下时用专门的站立帧（不再停在迈步的姿势上）。

## 测试清单（重点看这些）

1. 三种风格，哪种最像你心里的城市？哪些元素想保留、哪些不要？（可以混搭，比如骑楼的底层 + 港台的招牌）
2. 人和楼的比例：100% 和 85% 哪个更舒服？人是不是太小 / 太大？
3. 镜头：近、中、远，平时走路用哪一档？要不要允许玩家自己调？
4. 街道宽度、人行道宽度、楼的密度，看起来像不像真实的街？
5. 黄昏和夜晚的色调氛围对不对？
6. 像素颗粒感：人物和建筑的像素粗细是否一致，有没有哪里"糊"或者"太锐"？
7. 走到楼后面时楼会变半透明，这个效果能接受吗？
8. 有没有哪里看着特别别扭（透视、穿帮、接缝）？截图或者告诉我位置。

## 已知问题

- 建筑风格只改了 6 个街区，最上面一排商务区的高楼三种风格共用。
- 招牌都是空白或图标（AI 写中文会写错，正式版用程序叠加文字招牌）。
- 夜晚只是调暗，没有灯光。

## 灵感（可选，挑你喜欢的）

- **风格随街区变化**：老城区用骑楼、新区用港台街巷、商务区用玻璃楼，一座城里走着走着风格就变了，比统一一种更像真实的城市。
- **招牌用真实中文**：程序叠加像素字招牌（「陈记云吞面」「福安堂凉茶」），一眼就有亚洲烟火气；以后居民开店，招牌就是他起的名字。
- **季节和天气换装**：同一条街，雨天地面反光、店家撑起雨棚；春节挂满红灯笼。
- **骑楼下躲雨**：下雨时行人自动往骑楼下面走，主角走在骑楼下不会被淋湿。
- **拍照模式**：按一个键隐藏界面、拉远镜头，方便截图分享。
