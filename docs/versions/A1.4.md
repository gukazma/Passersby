# A1.4 · 修正 A1.3 反馈 + 街道生活（光影、小动物、车流、声音、对话头像）

## 怎么玩
双击 `运行.cmd`。新增：T 键时间快进（再按恢复）。其余按键同 A1.3。

## 这版做了什么
- A1.3 反馈修正：
  - 招牌字留出边距，不再超出招牌；
  - 走路步幅加大、步频降到正常（不再像踢正步）；跑步拉开步子，有腾空，约 2.7 m/s；
  - 被切一半的盆栽、外卖员被切掉的脚都已修好；
  - UI 字体清晰，去掉描边；
  - 不再在头顶显示门名，只提示能进的门；
  - 老伯被挡住时会绕行，不再顶着墙原地走；
  - 食客把碗放在桌上，用筷子吃；
  - 室内走不出房间。
- 对话：头像（每人 6 种表情，随台词变化）、10 颗好感度爱心（第一次聊天加好感）、头顶情绪气泡（爱心、音符、汗滴、省略号……）。
- 光影：时间流逝，影子随太阳变长变斜，傍晚以后路灯和店灯亮起，其中一盏会闪；车有车灯。
- 粒子：行道树落叶、汤锅蒸汽，都随风飘。
- 小动物：鸽子群（人靠近惊飞，绕一圈再落回）、麻雀、海鸥群、橘猫（睡觉）、三花猫（理毛、坐）、黑白小狗、旺财。
- 车流：的士、家用车、货车、小巴、外卖电动车、自行车；不追尾，有人过斑马线时停车。
- 声音：脚步声按鞋子区分（运动鞋、皮鞋、拖鞋、童鞋、爪子，室内是瓷砖声），近大远小；车经过声、喇叭、车铃、鸟叫、猫狗叫、蒸汽声；每个场景有自己的环境声。

## 测试清单（请重点看）
1. 走路、跑步的手感和步子，是否还像踢正步。
2. 对话头像的表情、爱心、气泡，风格对不对。
3. 傍晚到夜晚的光影、灯光是否好看，影子方向是否自然。
4. 鸽子惊飞、海鸥、猫狗的数量够不够、是否太吵。
5. 声音：脚步声、车声的大小和远近变化，环境声有没有听得清的人声（AI 生成，未经人耳检查）。
6. 车流的频率和速度。
