# A1.1 · 手感与穿帮修复

A1 试玩反馈（11-27）的第一批修改。城市还是 A1 那座 demo 城（3 种风格 × 2 种比例照旧可切），新城市要等《第一张地图设定集》确认后重建。

## 怎么玩

双击仓库根目录的 `运行.cmd`。

| 按键 | 作用 |
|---|---|
| 方向键 | 走路 |
| 按住 Shift | 跑步（新） |
| 1 / 2 / 3 | 城市风格 |
| R | 人和楼的比例 100% / 85% |
| Z | 镜头远近 |
| T | 时间色调 |
| P | 拍照模式（新）：隐藏界面、主角站住；方向键移动镜头（按住 Shift 更快），Z 切远近（多一档「全景」），回车或 F12 保存截图到仓库的 `截图/` 文件夹，再按 P 退出 |
| Tab | 自动巡游 |
| 空格 | 交互 |
| H | 隐藏说明 |
| Esc | 退出 |

## 改了什么

| 你的反馈 | 原因 | 修改 |
|---|---|---|
| 左右走路卡卡的、头像掉帧 | ① 物理 50 次/秒、屏幕 60 次/秒以上，每隔几帧就重复一帧；② 身体只在换动画帧时一下跳 4 像素；③ 主角往左走的那一行脸没有锁住，每帧都在变，几个 NPC 侧面头部也会上下跳 1 像素 | 物理改成 60 次/秒并开启画面插值；身体在每一帧时间里匀速前进（每 1/60 秒约 0.8 像素，速度不变）；侧面行走帧统一用同一个头 |
| 左右站立是斜着站、抬着一条腿 | 以前的侧面站立帧是从走路帧里拼出来的 | 11 个角色的左右站立帧全部重画：正侧面、站直、双脚着地；头的位置和走路帧一致，停下时头不会跳 |
| 想要跑步 | — | 按住 Shift 跑：新画的 8 帧跑步动画（前倾、腾空、摆臂），速度 90 像素/秒，约为走路的 1.9 倍 |
| 应该能自由穿越马路 | 马路中间有一道看不见的护栏，只在斑马线留口 | 主角不再受护栏限制，哪里都能过马路；车前面有人时会一直等，不会硬开过去（NPC 仍然走斑马线） |
| 树靠太紧、伸到路上、两棵交错 | 纵路人行道太窄，树坑直接放在路缘上，两侧的树挤在一起 | 每条人行道一排树、一棵一棵、等间距、不交错；纵路人行道加宽，树种在人行道外侧，树冠不进车道；横路的树只种在北侧人行道，南侧放路灯 |
| 屋顶的凸起没有盖住人 | 楼的前后遮挡是按一条水平线切的，楼顶的楼梯间、水箱伸出这条线的部分画在了人下面 | 逐列找出楼顶凸起的轮廓：凸起会盖住后巷里的人，碰撞也跟着轮廓走，不能再走到楼顶上 |
| 远镜头时说明文字太小 | — | 远镜头时界面按整数倍放大 |

## 测试清单

1. 左右走、上下走：还卡不卡？脚步和地面有没有打滑感？
2. 按住 Shift 跑：速度合适吗？跑步动作自然吗？（跑步时脚可能有一点点滑，告诉我明显不明显）
3. 停下来：四个方向的站立姿势对不对？停下的一瞬间头会不会跳？
4. 随便横穿马路，站在车前面看车会不会停下等你。
5. 走到后巷里，贴着南边那排楼的楼梯间、水箱走：会不会被它们挡住、会不会穿上去。
6. 行道树的位置和间距看着舒服吗？
7. 按 P 进拍照模式：移动镜头、切全景、回车保存，看看 `截图/` 文件夹里的图。

## 已知问题

- 街角的树和楼有被切掉的痕迹：这是 AI 画的街区图本身在边上被裁切了，在新城市重建时一起解决（出图时街区两端留白、以侧墙收尾）。
- 跑步的上下方向基本是原地踏步式动作，以后给新主角做跑步时一起重画。
- 主角还是原来的形象，新主角设计在设定集里，确认后替换。
